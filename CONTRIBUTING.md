# Contributing

This is a personal tool, published as it is. **Pull requests are not being accepted right now**, and
issues are closed by default — not out of rudeness, but because the project has one user and its
roadmap is their own archive.

If you find a security problem, do not open an issue: see `SECURITY.md`.

Forking is welcome and the license allows it. If you build on this, the parts most worth keeping are
the storage split (`internal/paste/storage.go`), the burn tombstone, and the second router for public
links (`internal/httpapi/public.go`).
